
Aplicación de diario de restaurantes.

## Cómo ejecutar:
1. Abrir Eclipse  e importar como File > Import > Existing Projects into Workspace.
2. Abrir la carpeta Taller6.
3. Buscar `VentanaPrincipal.java` y correrlo como aplicación de Java  (Run As > Java Application).
